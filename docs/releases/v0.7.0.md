# Release Notes: v0.7.0

**Release Date:** 2026-10-07

## Highlights

- **Codex CLI session reader**: `omnidevx.SessionReader` lists Codex
  sessions for the OmniDevX session catalog, with a title, the recent
  prompts a person typed, the working directory, branch, and the command to
  resume the session

## Added

- `omnidevx.SessionReader` implements `sessions.Reader` from
  `omnidevx-core` v0.4.0. It reads the newest `state_N.sqlite` for session
  metadata and the end of the rollout file for recent typed prompts, and
  tolerates Codex versions that lack optional columns
- A session is reported as `running` only when a `codex` process names its
  thread ID on the command line (`codex resume <id>`). A session started
  fresh and still open is `unknown`, not guessed

## Notes

- The reader reads titles and prompt text so that a person can recognize a
  session. That content stays in memory and is never turned into an event;
  the metadata-only collector is unchanged.
- Where `ps` is unavailable, including Windows, no session is reported as
  running.

## Dependencies

- `github.com/plexusone/omnidevx-core` from v0.3.0 to v0.4.0
- `modernc.org/sqlite` from 1.56.0 to 1.60.1
