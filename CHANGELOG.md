## [v0.7.0] - 2026-10-07

### Highlights

- **Codex CLI session reader**: `omnidevx.SessionReader` lists Codex sessions with title, recent typed prompts, working directory, branch, and a resume command, for the OmniDevX session catalog

### Added

- [omnidevx] `SessionReader` implementing `sessions.Reader`: reads the newest `state_N.sqlite` for session metadata and the rollout tail for recent typed prompts, tolerates missing optional columns, and reports `running` only when a `codex` process names the thread ID ([`c0902c1`](https://github.com/plexusone/omni-openai/commit/c0902c1))

### Dependencies

- Bumped `github.com/plexusone/omnidevx-core` from v0.3.0 to v0.4.0 ([`77555e6`](https://github.com/plexusone/omni-openai/commit/77555e6))
- Bumped `modernc.org/sqlite` from 1.56.0 to 1.60.1 ([`c873677`](https://github.com/plexusone/omni-openai/commit/c873677))

## [v0.6.1] - 2026-08-09

### Highlights

- **Realtime reliability fixes**: WebSocket events are no longer silently dropped under consumer backpressure, and message size is bounded to prevent OOM from malicious or buggy servers

### Fixed

- [realtime] `readLoop` blocks on a full events channel instead of dropping server events (audio deltas, transcripts, function calls) when the consumer falls behind ([`0cc6c8b`](https://github.com/plexusone/omni-openai/commit/0cc6c8b))
- [realtime] Bound WebSocket message size via `SetReadLimit(16MB)` to prevent unbounded memory allocation ([`f16649c`](https://github.com/plexusone/omni-openai/commit/f16649c))

### Documentation

- [omnidevx] Document Codex local format stability ([`eb339fa`](https://github.com/plexusone/omni-openai/commit/eb339fa))

### Tests

- [realtime] Regression test verifying `readLoop` blocks and delivers all events in order under a slow consumer ([`f1299dc`](https://github.com/plexusone/omni-openai/commit/f1299dc))

## [v0.6.0] - 2026-07-19

### Highlights

- **OmniDevX Codex CLI Collector**: new `omnidevx` package collecting developer-experience telemetry from Codex CLI local stores for the OmniDevX domain

### Added

- [omnidevx] Codex CLI collector: session metadata from the SQLite threads index (model, reasoning effort, git branch/origin, session tokens; content columns never selected) and per-session events from rollout JSONL (prompts, tool calls with name attribution, patch applies, task durations, per-turn token usage) ([`c5612a2`](https://github.com/plexusone/omni-openai/commit/c5612a2))
- [omnidevx] Graceful degradation: missing state database or schema drift falls back to rollout-only collection with diagnostics ([`c5612a2`](https://github.com/plexusone/omni-openai/commit/c5612a2))

### Dependencies

- Add github.com/plexusone/omnidevx-core v0.1.0 and modernc.org/sqlite v1.54.0 ([`c5612a2`](https://github.com/plexusone/omni-openai/commit/c5612a2))

### Tests

- [omnidevx] Collector tests on fabricated rollout fixtures and in-test SQLite databases: session dedup, per-turn usage, tool attribution, schema-drift fallback, newest-database selection, and privacy assertions ([`2cabfa8`](https://github.com/plexusone/omni-openai/commit/2cabfa8))
