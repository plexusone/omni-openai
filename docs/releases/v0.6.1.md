# Release Notes: v0.6.1

**Release Date:** 2026-08-09

## Highlights

- **Realtime reliability fixes**: WebSocket events are no longer silently
  dropped under consumer backpressure, and message size is bounded to
  prevent OOM from malicious or buggy servers

## Fixed

- `realtime.Session.readLoop` blocked on a full events channel instead of
  dropping server events (audio deltas, transcripts, function calls) when
  the consumer fell behind — a slow consumer now applies backpressure to
  the WebSocket read instead of losing data
- WebSocket message size is now bounded via `SetReadLimit(16MB)`, closing
  an unbounded memory allocation path from malicious or buggy servers

## Tests

- Regression test verifying `readLoop` blocks and delivers all events in
  order under a slow consumer
