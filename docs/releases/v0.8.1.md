# Release Notes: v0.8.1

**Release Date:** 2026-11-17

## Highlights

- **Transcription of any supported format**: the OmniVoice STT provider
  now names its upload, so OpenAI recognizes WAV clips and other formats
  instead of rejecting them
- **BCP 47 language tags**: `Language: "en-US"` works, as with other
  OmniVoice providers

## Fixed

- `Transcribe` computed a file name from `Encoding` but sent the audio as an
  unnamed stream, so OpenAI couldn't detect the format and returned
  "Unrecognized file format". The upload now carries the file name and a
  matching content type
- OmniVoice STT converted nothing in `Language`, and OpenAI expects ISO
  639-1 codes. A BCP 47 tag is now sent as its language (`en-US` as `en`,
  `pt_BR` as `pt`). An empty tag still asks OpenAI to detect the language,
  an undetermined tag such as `und` is never guessed as a language, and a tag
  that can't be parsed is passed through for the API to report

## Dependencies

- `golang.org/x/text` v0.44.0, now a direct dependency
- `modernc.org/sqlite` from v1.61.0 to v1.62.0

## Installation

```bash
go get github.com/plexusone/omni-openai@v0.8.1
```
